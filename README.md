# Engineering Insights Blog

A personal blog platform exploring software architecture, artificial intelligence, and research in software engineering.

## About This Blog

This blog serves as a platform for sharing insights, experiences, and knowledge in:

- **Software Architecture** – Design patterns, system architecture, and engineering best practices
- **Artificial Intelligence** – Practical applications of AI, with focus on computer vision and natural language processing
- **Full Stack Development** – End-to-end development practices, modern frameworks, and scalable solutions
- **Research & Innovation** – Emerging technologies, experimental approaches, and research-oriented problem solving
- **System Design** – Building scalable, secure, and user-centric applications
- **Technical Writing** – Making complex engineering concepts accessible and practical

## Content Focus

The blog covers topics including:

- Software engineering principles and best practices
- Full stack development techniques and frameworks
- AI integration into practical software systems
- Backend systems, APIs, and database design
- Open source contributions and clean architecture
- Real-world problem solving and case studies
- Performance optimization and reliability engineering

## Writing Posts (Markdown/MDX)

Add new posts as `.mdx` (or `.md`) files inside:

- `client/content/posts/`

Each post uses frontmatter for metadata. Example:

```md
---
title: "My Post Title"
description: "Short summary shown on cards and search."
date: "2026-01-28"
tags: ["AI", "System Design"]
image: "/some-image.jpg" # optional (can also be an absolute URL)
featured: true           # optional
featuredOrder: 1         # optional (lower = higher priority)
---
```

To change the **featured post(s)** on the homepage, edit the frontmatter and toggle `featured` / `featuredOrder`.
